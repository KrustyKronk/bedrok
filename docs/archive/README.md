# Archive

History. **It contradicts the present on purpose.** Do not read anything in here
unless a question sends you to it specifically, and never treat it as current.

What belongs here: superseded plans, retired designs, documents whose conclusions
have been overtaken. What does not: anything still open, which lives in
`STATE.md`, and dated evidence, which lives in `docs/research/` and is never
rewritten because a measurement edited after the fact is not a measurement.
